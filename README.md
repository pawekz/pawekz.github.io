# Pawekz · Personal Portfolio

Hi, I'm Pawekz. This repository is home to my personal portfolio—a place to share my skills, school projects, and the things I build along the way.

[Portfolio](https://pawekz.github.io/) · [GitHub profile](https://github.com/pawekz)

## About the portfolio

I'm putting together a collection of my work to show what I'm learning and how I apply it through projects. The portfolio has dedicated sections for skills and school projects, with space to add project descriptions, technologies, screenshots, and source code links.

The site is currently being built. Specific skills and project entries will be added as the portfolio takes shape.

## Built with

- HTML for page structure and content
- CSS for responsive layouts and styling
- GitHub Pages for hosting

The site uses plain HTML and CSS, with no framework, package installation, or build step.

## Repository contents

| File | Purpose |

| `index.html` | Portfolio homepage, skills, and school projects |
| `styles.css` | Shared styling and responsive layout |

## Preview locally

From the repository directory, run:

```bash
python3 -m http.server 8000
```

Then open [localhost:8000](http://localhost:8000). Changes to the HTML and CSS appear when you refresh the page.

## Publish with GitHub Pages

Push the site files to `main`, then open [Settings → Pages](https://github.com/pawekz/pawekz.github.io/settings/pages). Choose **Deploy from a branch**, select **main** and **/ (root)**, and save.

The portfolio's address is [pawekz.github.io](https://pawekz.github.io/). See the [official GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart) for setup details.
